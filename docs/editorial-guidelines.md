# 投研叙事与文风纪律指南

本指南面向所有负责 MarketTracker 文本生成、指标解读与研判编写的智能代理（Agent）与分析人员。系统定位为**严肃金融数据看板与专业决策终端**，所有文本输出必须符合专业机构卖方研究（Sell-side Equity Research）与彭博终端（Bloomberg Terminal）的标准。

---

## 1. 核心定位与语调原则

- **目标受众**：公募/私募基金经理、科技与大宗商品研究员、专业机构投资人。
- **基准语调**：客观中立、冷峻精炼、逻辑严密、事实优先。
- **杜绝倾向**：严禁自媒体情绪化表达、散户新手教学口吻、居高临下的劝诱及泛泛而谈的论调。

---

## 2. 禁用表达与专业机构术语替换映射表

任何进入生产环境的数据或组件文本，必须严格遵循下述术语标准：

| 严禁表述（口语/俗语/主观夸张） | 机构专业替换术语 | 规范说明 |
| :--- | :--- | :--- |
| **抢芯 / 抢货 / 囤货** | 供应链锁量 / 芯片保供锁定 / 战略备货 | 准确反映供应链契约与产能分配机制 |
| **水龙头 / 需求水龙头** | 需求底座 / 资本开支驱动源 | 消除生活化隐喻，陈述产业传导动因 |
| **交不出货 / 拿不到货** | 交付脱节 / 产线良率与供给约束 | 客观定性制造与交付瓶颈 |
| **吃掉几个点毛利 / 吞噬利润** | 成本转嫁困难 / 毛利率承压 / 成本挤压 | 严谨陈述财务指标承压事实 |
| **谁在占出货** | 800G / 1.6T 出货结构 / 代际渗透率 | 规范产业代际升级表达 |
| **避坑指南 / 警惕认知陷阱 / 最大的误判** | 预期偏差 / 路径演进分歧 / 商业化节奏差异 | 严禁以主观说教取代客观分歧阐述 |
| **拒绝XX焦虑 / 短期不必恐慌** | 中远期技术路线 / 近端替代有限 | 严禁情绪化与心理抚慰式用语 |
| **普通投资者 / 散户 / 我们 / 大家** | 市场 / 机构持仓 / 产业侧 | 严禁假定读者身份或代入主观视角 |
| **极其亮眼 / 急剧 / 暴增 / 无可撼动** | 高增阶段 / 明显提速 / 居出货主力 | 杜绝无度量衡的最高级与夸张修饰 |
| **真假壁垒 / 虚假泡沫错觉** | 成本与壁垒结构 / 静态估值分位与前瞻中枢 | 客观分析估值偏离度，不做价值评判 |
| **继续拿 / 割肉 / 适合买入** | 保持观察 / 估值消化 / 依赖下一期披露验证 | 严禁输出投资建议或非法交易指令 |

## 3. 数据引用与事实陈述规范

1. **宏观指标联动唯一性**：
   - 云厂商资本开支、A 股 TMT 成交占比、融资买入强度等跨板块指标，必须单一引用 `src/data/techSemiData.json` 对应的 Actions 读数，严禁在子板块中另行构造或平行写死未经核实的年度总额。
2. **公开统计与预测必须显式注明来源**：
   - 供应链财务数据：明确注明对应上市公司财报期次（例如：“中际旭创 2026 年一季报”）。
   - 行业市占率统计：明确注明数据提供商（例如：“LightCounting 统计口径”）。
   - 市场规模及增速预测：明确注明研报机构与测算性质（例如：“高盛行业研报预测（情景测算）”）。
3. **前瞻估值与行情隔离**：
   - 动态 PE / PEG 指标仅作为理论测算框架呈现，必须显式标注“情景测算”，严禁断言为“合理估值”或“目标定价”。
4. **研判结构范式**：
   - 业务研判统一采用「客观事实从句 + 边际变化说明 + 关键观察节点」的语法结构。数据缺失时保持「未接入」，不臆造趋势结论。
