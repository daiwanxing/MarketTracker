# MarketTracker

Static GitHub Pages tracker for A-share ETF **588170**（科创半导体ETF华夏 / 华夏上证科创板半导体材料设备主题ETF）.

GitHub Actions appends one quote snapshot to `snapshots.json` every 5 minutes (`*/5 * * * *`, UTC) and on manual `workflow_dispatch`. The page lists those snapshots with the newest line first.

Public site: https://daiwanxing.github.io/MarketTracker/
